# Harvey Ciphers Personal Site

This repository hosts the source for Harvey Ciphers' personal branding site on GitHub Pages.

## Structure

- `index.html` – Main landing page with sections for hero, about, skills, projects, testimonials, and contact.
- `assets/css/styles.css` – Styling, responsive layout, and accessible color/typography system.
- `assets/js/main.js` – Minor enhancements like mobile navigation and smooth scrolling.
- `assets/img/profile-placeholder.svg` – Placeholder hero illustration.

## Local Development

The site is static, so you can open `index.html` directly in a browser. For live reloading, serve the directory with any static HTTP server, e.g.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
