A document in the `tutorials` collection rather than a blog post. Collections
have no date requirement in the filename and get their own permalink structure,
which makes them the right shape for documentation, release notes, or profiles.

## Steps

1. Create a repository.
2. Add an `index.md` with front matter.
3. Enable Pages in **Settings → Pages**.
4. Wait for the first build, then load the URL.

That is the whole process. There is no server to configure because there is no
server.
