How the deep links survive a refresh

GitHub Pages has no rewrite rules, so a request for /demos/spa/roadmap finds no file and falls through to 404.html. That page reads the path, redirects to this entry point with the route in a query string, and the router restores the real URL with history.replaceState(). The visitor sees one brief redirect and the correct page.
